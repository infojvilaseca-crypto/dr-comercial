Sincronització al Núvol (Supabase)

Sincronització instantània: En posar les teves claus de Supabase (gratuït), les teves dades estaran sincronitzades automàticament entre el teu ordinador i el teu mòbil.

Com crear la base de dades en 1 minut:

  1. Crea un projecte gratuït a Supabase.com.
  2. Ves a la pestanya SQL Editor i enganxa l'script que tens generat al fitxer supabase_schema.sql.
  3. Copia la URL i la clau Anon des de Project Settings > API i enganxa-les aquí.
